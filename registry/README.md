# Videoroom — общие комнаты

Реестр комнат для расширения [Videoroom](https://github.com/Beetlejuice8921/videoroom-cinema):
видео одного события, снятые с разных ракурсов, со сдвигами для синхронного просмотра.

- `index.json` — какое видео в какой комнате;
- `rooms/<id>.json` — сами комнаты.

## Как добавить комнату

В расширении: меню → у комнаты кнопка **🌐 Поделиться**. Откроется заявка
(issue) с JSON комнаты. Отправьте её, бот проверит JSON и добавит комнату
в реестр, ответ придёт в той же заявке.

Обновить свою комнату можно так же: ещё раз нажмите «Поделиться». Изменить
комнату может только её автор.
